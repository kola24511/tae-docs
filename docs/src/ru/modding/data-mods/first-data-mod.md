# Создание первого дата-мода

В этом руководстве мы возьмём готовый Example Data Mod,
разберём его содержимое и установим в игру.

Пример добавляет синий кристалл, который выпадает
с тестового моба: от 1 до 3 предметов с вероятностью 25%.

Для работы с дата-модом не нужны C#-код, SDK
или инструменты сборки.

## Получение проекта

Откройте [репозиторий Example Data Mod](https://github.com/kola24511/TAE-example-data-mod)
и скачайте исходники через **Code → Download ZIP**.

Распакуйте архив в отдельную папку.
Для удобства её можно назвать `ExampleDataMod-1.0.0`.

Если используете Git, клонируйте проект:

```sh
git clone https://github.com/kola24511/TAE-example-data-mod.git ExampleDataMod-1.0.0
```

Все необходимые файлы уже находятся в примере.
Можно сразу установить его в игру или сначала изменить контент.

## Структура проекта

```text
ExampleDataMod-1.0.0/
├── module.json
├── README.md
├── Data/
│   ├── items.json
│   └── loot.json
├── Icons/
│   └── crystal.png
└── assets/
    └── lang/
        ├── en/
        │   └── items.json
        └── ru/
            └── items.json
```

| Путь | Назначение |
| --- | --- |
| `module.json` | Данные мода и пути к файлам контента |
| `Data/items.json` | Описания предметов |
| `Data/loot.json` | Правила выпадения |
| `Icons/crystal.png` | Изображение предмета и мода |
| `assets/lang/` | Переводы |
| `README.md` | Краткая инструкция по использованию примера |

Пути в JSON указываются относительно папки мода.
Соблюдайте регистр букв в именах папок и файлов.

## Подключение контента

Откройте `module.json`. В блоке `content` перечислены файлы,
из которых игра загружает предметы и правила выпадения:

```json
{
  "content": {
    "items": ["Data/items.json"],
    "loot": ["Data/loot.json"]
  }
}
```

Это фрагмент готового манифеста, а не весь файл.
Пути уже настроены в примере. Если переименуете файлы контента,
обновите соответствующие записи.

Общие поля манифеста описаны в [общих основах](../getting-started/common-basics#манифест).

::: tip Собственный мод
Для своего мода измените ID, название, описание и автора в `module.json`.
Обновите ID мода в ссылках на предметы в `Data/loot.json`,
а также переводы названия и описания мода.
:::

## Предмет

Откройте `Data/items.json`:

```json
{
  "schemaVersion": 1,
  "items": [
    {
      "id": "blue_crystal",
      "name": "Blue crystal",
      "description": "A blue crystal added by a data mod. Drops from the test mob with a 25% chance, 1–3 at a time.",
      "icon": "Icons/crystal.png",
      "maxStack": 99,
      "weight": 1
    }
  ]
}
```

Массив `items` содержит описания предметов.

| Поле | Назначение |
| --- | --- |
| `id` | Локальный идентификатор предмета |
| `name` | Название при отсутствии перевода |
| `description` | Описание при отсутствии перевода |
| `icon` | Путь к изображению |
| `maxStack` | Максимальное количество в одном стаке |
| `weight` | Вес одного предмета |

В этом примере полный ID предмета — `example.crystal:blue_crystal`.
Правила идентификаторов описаны в [общих основах](../getting-started/common-basics#id-мода-и-предметов).

## Изображение

В примере уже есть `Icons/crystal.png`. Чтобы заменить изображение,
замените этот файл или обновите поле `icon` в `Data/items.json`.
Иконка мода задаётся отдельно в `module.json`.

Общие правила путей и изображений — в [общих основах](../getting-started/common-basics#ресурсы-и-изображения).

## Выпадение

Откройте `Data/loot.json`:

```json
{
  "schemaVersion": 1,
  "loot": [
    {
      "table": "base:test-mob-loot",
      "item": "example.crystal:blue_crystal",
      "chance": 0.25,
      "minAmount": 1,
      "maxAmount": 3,
      "rarity": "uncommon"
    }
  ]
}
```

Это правило добавляет кристалл в существующую
таблицу выпадения `base:test-mob-loot`.

| Поле | Назначение |
| --- | --- |
| `table` | Идентификатор таблицы выпадения |
| `item` | Полный идентификатор предмета |
| `chance` | Вероятность выпадения от `0` до `1` |
| `minAmount` | Минимальное количество |
| `maxAmount` | Максимальное количество |
| `rarity` | Редкость |

`chance: 0.25` означает вероятность 25%.
При успешном выпадении игрок получит от 1 до 3 кристаллов.

::: info Источник предмета
Описание предмета само по себе не настраивает выпадение.
За него отвечает правило в `Data/loot.json`.

Мод использует существующего тестового моба
и не создаёт новых мобов.
:::

Если измените ID мода или предмета,
обновите значение `item` в правиле выпадения.

## Переводы

Готовые переводы находятся в `assets/lang/en/items.json`
и `assets/lang/ru/items.json`.
При изменении названия и описания кристалла обновите ключи
`item.blue_crystal.name` и `item.blue_crystal.description`.

Для названия и описания мода используются `mod.name` и `mod.description`.
Формат файлов и выбор запасного языка описаны в
[общих основах](../getting-started/common-basics#локализация).

## Установка

Сборка дата-мода не требуется.
Его рабочая папка уже является готовым модом.

1. Закройте игру.
2. Скопируйте папку мода в `Mods` рядом с исполняемым файлом игры.
3. Запустите игру.
4. Откройте раздел **«Модификации»**.

Проверьте расположение манифеста:

```text
Mods/ExampleDataMod-1.0.0/module.json
```

Мод должен появиться со статусом **«Загружен»**.

## Проверка предмета

Зайдите в мир и убейте тестового моба,
использующего таблицу `base:test-mob-loot`.

Кристалл выпадает с вероятностью 25%,
поэтому одно убийство не гарантирует его получение.

Для проверки можно временно установить:

```json
{ "chance": 1 }
```

Это фрагмент правила: измените поле `chance` в существующем `Data/loot.json`.

После проверки верните `0.25`.

Проверьте изображение, название и описание предмета
в инвентаре.

::: info Изменения файлов
Если редактируете отдельную рабочую копию проекта,
скопируйте изменённые файлы в установленный мод.

После изменений перезапускайте игру.
:::

## Распространение

Готовую папку можно упаковать в ZIP-архив
и прикрепить к релизу вашего репозитория на GitHub.

Структура архива:

```text
ExampleDataMod-1.0.0.zip
└── ExampleDataMod-1.0.0/
    ├── module.json
    ├── Data/
    ├── Icons/
    └── assets/
```

В архив достаточно включить манифест,
файлы контента, изображения и переводы.

Папку `.git` включать не нужно.
Перед установкой игрок должен распаковать архив.
