# Возможности и ограничения

Система моддинга поддерживает C#-моды и дата-моды.
Они используют общий формат манифеста, идентификаторов,
ресурсов и локализации.

## C#-моды

C#-мод содержит скомпилированную DLL и необходимые ресурсы.

Он может:

- Выполнять собственную логику через публичный API.
- Регистрировать доступные типы контента.
- Использовать API других модов.
- Предоставлять собственный API для других мододелов.

Для сборки нужны .NET SDK и SDK игры.
Игроку для установки готового мода SDK не требуется.

## Дата-моды

Дата-мод описывает контент в JSON-файлах.
Для его создания не нужны C#-код, SDK или сборка проекта.

Возможности дата-мода ограничены типами контента
и настройками, которые поддерживает игра.

## Доступный контент

Сейчас оба формата позволяют:

- Добавлять ресурсные предметы.
- Задавать название, описание, размер стака и вес предмета.
- Подключать изображения предметов.
- Добавлять предметы в существующие таблицы выпадения.
- Добавлять переводы названий, описаний и других текстов мода.

Добавление предмета само по себе не делает его доступным
в игровом мире. Нужно отдельно настроить способ получения,
например выпадение из существующей таблицы лута.

## Клиентские и серверные моды

В манифесте указывается сторона работы мода:

| Значение `side` | Назначение |
| --- | --- |
| `client` | Клиентская часть игры |
| `server` | Серверная часть игры |
| `both` | Клиент и сервер |

C# и JSON определяют способ создания мода,
а `side` — где он должен работать.

::: info Предметы и выпадение
Для модов, регистрирующих предметы и правила выпадения,
сейчас требуется `side: "both"`.
:::

## Текущие ограничения

- Регистрация нового контента пока ограничена ресурсными предметами и добавлением правил выпадения.
- Для нового оружия, рецептов, существ и других типов контента ещё нет готового публичного API.
- ZIP-архивы необходимо распаковывать перед установкой.
- Изменения модов применяются после перезапуска игры.
- Автоматическая проверка совместимости наборов модов клиента и сервера пока не реализована.

В мультиплеере устанавливайте одинаковые версии модов,
добавляющих игровой контент, на клиент и сервер.

## Идентификаторы контента

Каждый предмет получает идентификатор вида
`mod_id:item_id`, например `example.mod:test_crystal`.

Название предмета можно менять и переводить.
Идентификатор используется в сохранениях и ссылках
на контент, поэтому его изменение требует особого внимания.
