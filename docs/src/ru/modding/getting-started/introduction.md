# Введение в моддинг

Моды позволяют расширять The Adventurer's Era собственным
контентом и игровой логикой.

Доступны два способа создания модов:

- **C#-моды** — код, использующий публичный API игры.
- **Дата-моды** — JSON-файлы и ресурсы без написания C#-кода.

Сейчас можно добавлять ресурсные предметы, изображения,
переводы и выпадение предметов из существующих таблиц лута.

Для начала выберите руководство по созданию C#-мода
или дата-мода. Если вы хотите установить готовый мод,
откройте инструкцию по установке.
